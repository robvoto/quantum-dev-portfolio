# Bell States and Quantum Teleportation

`teleportation.py` is a learning example that builds the main stages of quantum teleportation with Qiskit:

1. prepare a Bell pair;
2. prepare the source qubit;
3. couple and measure the sender qubits;
4. apply the classical X/Z corrections to the receiver qubit.

Install the verified project dependency with:

```powershell
python -m pip install -r requirements.txt
```
